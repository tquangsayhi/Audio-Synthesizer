Synthesis changes VHDL code language into logical ciruit standard gates. For example flip-flops and Look-Up-Tables.
Inputs: HDL source code files and IP block definitions.
Outputs: A synthesized logical netlist.

Implementation maps the logical netlist that we got from synthesization into physical silicon of the target FPGA. It puts the logic components into specific physical coordinates on the chip and routes the electrical wire connections between them.
Inputs: The synthesized netlist and physical constraint files (XDC).
Outputs: A fully routed physical design and also it gives performance reports detailing timing, slack, power consumption and hardware utilization.

Bitstream generation converts the physical routing data into a binary configuration file and downloads it to the FPGA chip. It sets the internal SRAM switches and configures the hardware to match the design.
Inputs: The implemented and routed physical design.
Outputs: A binary bitstream file.
