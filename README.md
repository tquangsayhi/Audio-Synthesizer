RTL Design and Logic Synthesis
A collection of digital hardware design exercises developed during the Logic Synthesis course at Tampere University.
The repository demonstrates practical experience with VHDL, Verilog, RTL design, finite state machines, testbench development, simulation, FPGA synthesis, and timing analysis.
Tools: AMD Vivado, ModelSim, VHDL, Verilog.
Topics: Combinational and sequential logic, FSM design, RTL simulation, hardware verification, synthesis, and FPGA implementation.
